社區會議記錄 Bot

LINE 語音會議 → 雅婷台語辨識 → Claude 精簡整理 → 回傳社區群組。所有未知數已用真實素材驗證，本文供逐項確認後開工。

01資料流 · 一場會議走過的路

五個環節，從按下錄音到會議記錄貼回群組。每個環節都標了它現在的狀態。

A 開會 · 本地錄音 LINE 通話開會時，一支手機／電腦錄整場音檔。LINE 通話聲音 Bot 拿不到，所以自己錄。 限制 · 需人工錄音
B 上傳 · LINE Bot 收件 會後把音檔傳進社區 LINE 群組並 @Bot。Bot 收到音檔，觸發後端處理。 入口 · LINE Messaging API
C 辨識 · 雅婷 ASR API 後端把音檔送雅婷。台語→繁中逐字稿，並自動分好語者 1／2／3。這兩關雅婷全包。 已驗證 · 14.5 分鐘真實會議
D 整理 · Claude API 逐字稿丟給 Claude，濃縮成「議題／決議事項／負責人／共識」的精簡會議記錄。 已驗證 · 效果見附件
E 回傳 · 貼回 LINE 群組 Bot 把整理好的會議記錄推播回社區群組，大家直接讀。一場會只用 1 則推播額度。 輸出 · LINE Push Message

🛡 架構隔離原則

這套 Bot 會跟你現有的 Yba_order 叫貨系統共用同一台 VPS（5.104.87.209），但完全獨立部署：獨立 Docker 容器、獨立網域、獨立資料。絕不碰 yba-order 的容器、資料庫或 Nginx 設定。你的正式叫貨系統一行都不會動到。

03開工步驟 · 誰做什麼

紅色是只有你能做的（要你的帳號／金鑰）；黑色是我來寫程式。照順序走。

  1. 申請雅婷 API 金鑰你 · 5 分鐘
    到 developer.yating.tw 用 Google 登入 → 建一組 API Key → 給我。程式一定要它才能跑。
  2. 建立 LINE 官方帳號 + Messaging API你 · 10 分鐘
    LINE Developers 後台建 Channel，拿 Channel Access Token 與 Channel Secret，把 Bot 加進社區群組。
  3. 搭後端服務我 · 寫程式
    一支輕量後端：收 LINE 音檔 → 呼叫雅婷 → 呼叫 Claude → 回推 LINE。放進 VPS 獨立容器。
  4. 設定雅婷／Claude／LINE 三方串接我 · 寫程式
    金鑰進 .env（不外洩），串好三段 API，處理音檔格式轉換與非同步等待辨識結果。
  5. 調 Claude 整理提示詞（會議記錄格式）我 · 可調
    定義輸出格式：議題／決議事項／待辦／負責人。你看過樣式後可微調到你要的樣子。
  6. 部署到 VPS 獨立容器我 · 部署
    獨立 Docker + 子網域（如 meeting.yen-design.com），設 LINE Webhook。完全不動 yba-order。
  7. 真實會議實測 + 驗收你 + 我
    下次開會錄音跑一輪完整流程，確認會議記錄品質，微調後正式上線。
